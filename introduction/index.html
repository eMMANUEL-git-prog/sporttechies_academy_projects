What is the Web?

The World Wide Web is a collection of pages you view in a browser.

  • Pages contain text, images, videos, and clickable links.
  • You jump from page to page by clicking (surfing the web).
  • Think of it like a giant interactive digital book.
Web vs Internet: Internet = roads & infrastructure. Web = cars & content you see.

What is a Browser?

A browser is an application that displays web pages.

  • Type a web address → browser requests the page → shows it to you.
  • It also remembers history, bookmarks, and protects your privacy.

Website vs Web App

Website Web App
You mostly read or watch You can DO things (interact)
Example: news article, blog, restaurant menu Example: Gmail, Facebook, Google Maps
Usually no login needed Often requires login or stores your data
YouTube is mostly a website to watch, but when you like, comment, it acts like a web app. Boundaries can be blurry!

Frontend vs Backend

Frontend
What you see & click
Runs in your browser
Backend
Hidden server & database
Processes data & logic

Restaurant Analogy (easy!)

  • Frontend = Dining room (menu, table, waiter taking order)
  • Backend = Kitchen + storage (chef, fridge, ingredients, recipes)
  • Fullstack developer = can work as waiter AND cook

Frontend Technologies

These three languages are the heart of every website:

Technology Job (one sentence)
HTML Structure – "this is a heading, this is a paragraph, this is a button"
CSS Style – "make it red, center the image, add a cool shadow"
JavaScript Interactivity – "when clicked, show an alert" or "change content live"

Every modern website uses at least HTML + CSS. JavaScript adds the magic.

Backend Technologies (examples)

These live on servers (remote computers) and do the heavy lifting.

Languages
Node.js, Python, PHP, Java, C#
Frameworks
Express, Django, Laravel, Spring Boot
pre-built toolkits
Databases
MySQL, PostgreSQL, MongoDB
store & organize data (like a digital fridge)

Don't memorize these names. Just know that backend has many options.

What is a Fullstack Developer?

  • Works on both frontend and backend parts of a web app.
  • Can build a complete website from scratch (visual + database + logic).
  • Understands how the dining room AND the kitchen operate together.
  • Fullstack = flexible and valuable in tech teams.
Many developers specialize in one area. Fullstack developers know enough to connect everything.

Simple Web Request Flow

  1. You click a link or type a website address (e.g., sporttechies.com or runnermkt.com)
  2. Your browser sends a request across the internet to a server.
  3. The server processes the request and sends back a response (the webpage).
  4. Your browser renders the page on your screen.
You → Browser → Internet
Server → Response → Display

Analogy: Ordering pizza — you call (request), kitchen makes it, delivery brings it (response).

Tools for Web Development

  • A browser (Chrome, Edge, Firefox) — you already have one!
  • Code editor – where developers write code. We'll use VS Code (free, powerful).
  • A simple folder on your computer to save projects.

No terminal or complicated installs yet. Just understanding the environment.

VS Code is like a supercharged Notepad with colors and helpful tools.

After install: open VS Code, drag your folder into it, and create a file called hello.html (no code yet, just get comfortable).
